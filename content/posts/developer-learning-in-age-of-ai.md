What do developers need in the age of AI? Is this the same for new and existing developers? How should this affect our plans? 

I've been working in developer relations for a year now, and honestly what a wild time to join. This time a year ago, GPT-5 had just been released and GPT-5-Codex was just about to be. Coding agents were going from useful advisors to something that did the work for you. People were just starting to play with vibe coding, but mostly it seemed fairly frowned upon. I reviewed some work by a vibe coding colleague was a spaghetti mess of half implemented functions. 

It wasn't long before everything flipped. November-December 2025 and January 2026 seemed to be where the mood really changed—people realised that the code produced was actually working. 

Now, in October 2026, it seems normal to say that code isn't written by hand anymore. Why would I code by hand when I can have a trustworthy agent write exactly what I want in a tenth of the time? 

But all this leaves us, those working to improve the developer experience and create materials to help developers learn, in a tough spot. Do developers still learn in the same way? If I was trying to learn about the stuff I am trying to teach, would I look for a course about it, or would I just ask AI? 

Is the job of developer relations now just making our information more discoverable by AI? Providing content for AI to consume? If I create fun interactive tutorials designed for humans, will anyone even take it? 

We're in this in-between phase where all the pieces have been launched into the air and we're just not quite sure how they are going to land. Will developers need to know how systems work in the future? Are we all just going to put a description into a magic box and get a fully functioning application out? I'm I going to spend my life asking AI to generate instructions for another AI? 

That experience looks bleak and I don't know how to add promise to it.
